# vrclt v0.19.1

VR controls are organized into pages so translation and subtitle controls are
easier to find while wearing a headset. This update also brings Soniox's
speaker-context setting and effective silence timeout into the VR panels.

## Changes

- **SteamVR Dashboard:** open the SteamVR menu and select the vrclt icon.
  **Live** groups translation, subtitles, languages, and connection/error status.
  **Audio** contains microphone and voice-output selection plus translated-voice
  volume. **Layout & app** groups panel positioning and app controls.
- **Wrist menu:** **Live** groups frequent translation and subtitle controls;
  **Settings** contains runtime restart, subtitle sizing, and panel positioning.
  Existing gaze/grip and controller interactions remain available.
- **Soniox in VR:** both panels show the speaker-context switch and the effective
  silence timeout, using the same saved value as the PC UI. Speaker diarization
  remains enabled with either switch state.
- **Spoken-language controls:** Qwen's required source-language selection and
  Soniox's optional recognition hints are available on the SteamVR Dashboard.
  The wrist menu selects translation output and subtitle languages.
- **Documentation:** English, Korean, Japanese, and Chinese READMEs describe the
  VR pages and retain the complete Soniox signup and setup instructions.
- **Desktop spacing:** translation/subtitle buttons and language fields keep
  their row spacing in smaller windows; the Soniox silence timeout stays on one line.

## Soniox speaker context and silence

The recent Soniox behavior is included in this version: **Keep speaker context**
is on by default and retains recognition sessions through short pauses, then
disconnects after **60 seconds of silence**. Set
`soniox.speaker_context_idle_sec` in Settings to adjust the limit from 5 to 600
seconds. With the option off, `audio.mic_idle_disconnect_sec` is used instead
(15 seconds by default). Speech resumes the connection automatically, starting
a new speaker context. Existing saved switch choices are preserved.

The silence limit follows speech activity rather than continued transmission
of silence or keepalive data. More conservative turn boundaries reduce early
finalization, but do not guarantee that one person always receives the same
speaker number. Distinct speaker IDs returned by Soniox stay separate, and
numbers remain local to each recognition session.

Soniox bills the full connected recognition stream, including silence and
keepalive time, also in text-only mode. See the
[Soniox keepalive billing guide](https://soniox.com/docs/stt/rt/connection-keepalive).
For signup, API keys, balance, app setup, and troubleshooting, see the
[English guide](../../README.md#3c-soniox-api-key) or
[한국어 안내](../../README.ko.md#3c-soniox-설정).

## Installation

Download `vrclt-v0.19.1-windows-x64.exe` and its `.sha256` checksum. Close the old
app before launching the new executable. This is a single Windows executable
with a native PySide6 window and tray menu. VB-Audio Virtual Cable is required
for virtual microphone routing; select `CABLE Output` as the target app's
microphone.

Settings remain in `%LOCALAPPDATA%\vrclt\config.yaml`; no configuration file is
bundled alongside the executable. Run the new executable once to refresh the
path used by SteamVR auto-start.

## Validation limits

VR rendering and button behavior are checked with headless/mock tests. Soniox
has local mock-WebSocket coverage. These checks do not establish physical
headset behavior or live speaker-recognition accuracy; physical VR controls and
paid live Soniox calls have not been verified.
